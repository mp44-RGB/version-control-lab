# version-control-lab
实验六 版本控制 Git 练习仓库

## 实验说明

本仓库用于《实验六 版本控制》课程练习，主要完成以下操作：

- 在本地使用 Git 管理项目文件；
- 新建 `readme-edits` 分支并在分支上修改文件、提交（commit）；
- 将分支推送到远程仓库，发起 Pull Request（PR）；
- 将 Pull Request 合并（Merge）到 `main` 分支。

## 操作记录

1. 从远程仓库克隆项目到本地；
2. 新建分支 `readme-edits`；
3. 修改 README 文件并提交；
4. 推送分支到远程仓库；
5. 发起 Pull Request 并合并。

## 版本控制说明

Git 是一个分布式版本控制系统，可以记录文件的每一次修改，方便多人协作和版本回溯。
本实验通过完整走一遍「建分支 → 提交 → 发起 PR → 合并 PR」的流程，理解版本控制的基本工作方式。
